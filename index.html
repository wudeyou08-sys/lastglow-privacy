隐私政策

《经典吃豆人：最后一颗》 · 开发者：星辉ai工作室
适用版本：Android 1.0.0（versionCode 10） · 生效日期：2026 年 11 月 1 日

本政策说明《经典吃豆人：最后一颗》（以下简称“本游戏”）如何处理与你有关的信息。本游戏是一款单机游戏，不提供账号系统，不要求你注册或登录。

一、我们收集的信息

本游戏不收集、不上传、不共享你的姓名、手机号、邮箱、通讯录、短信、相册、摄像头、麦克风内容，也不读取你的精确位置。

为展示广告，本游戏的第三方广告 SDK 会处理必要的设备与网络信息，详见下文第五节。

二、网络权限

本游戏的 Android 安装包声明了 INTERNET 与 ACCESS_NETWORK_STATE 权限，用于向广告服务器请求并展示广告。除广告请求外，本游戏不会向任何服务器上传你的游戏进度或个人信息。

三、本地数据

游戏进度、设置项（声音、画面效果等开关）仅保存在你设备的本地存储中，不会离开设备。卸载本游戏后，这些本地数据会随之删除。

四、第三方服务与 SDK

本游戏接入 TapADN 广告 SDK（由上海艾得蒽数字科技有限公司及其关联方提供）用于展示激励视频广告。该 SDK 可能为完成广告投放、广告监测归因、反作弊与广告统计分析而收集设备标识符（如 OAID）、网络状态、设备型号与系统版本等信息。

TapADN SDK 的隐私政策与合规说明：

  • SDK 隐私政策
  • SDK 合规使用说明

除 TapADN 外，本游戏未接入统计分析、支付或社交分享类 SDK。

若你通过 TapTap 客户端以 TapPlay 形式游玩，TapPlay 的运行环境、实名认证与防沉迷由 TapTap 平台提供并按其隐私政策处理。

五、广告与激励

游戏内部分奖励（手提灯、手电筒、复活等）可选择观看激励视频后领取。广告仅在你主动点击领取时展示，不会在游戏过程中自动弹出，也不会打断正在进行的对局。

若广告加载失败，本游戏会直接发放该奖励，不会因此阻碍你继续游玩。

本游戏不含内购、不含抽卡与开箱机制，也不含社交与聊天功能。

六、未成年人保护

本游戏不含付费项目，广告内容由广告平台按其合规要求审核投放。未成年人防沉迷与实名认证由 TapTap 平台统一提供。若你认为我们在未成年人保护方面存在问题，可通过下方联系方式告知。

七、信息安全

本游戏自身不收集也不传输个人信息。设备本地的游戏存档受你设备自身的安全机制保护。广告相关数据由广告服务方按其隐私政策处理。

八、政策更新

若本游戏后续版本新增联网功能、账号功能或第三方服务，我们会在本页面更新政策，并在更新时标注新的生效日期。重大变更会在游戏更新说明中提示。
